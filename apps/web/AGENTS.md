## Vite Configuration

```ts
// vite.config.ts
import { defineConfig } from "vite";
import { tanstackStart } from "@tanstack/solid-start/plugin/vite";
import { tanstackRouter } from "@tanstack/router-plugin/vite";
import viteSolid from "vite-plugin-solid";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  server: { port: 3001 },
  resolve: { tsconfigPaths: true },
  plugins: [
    tailwindcss(),
    tanstackRouter({ target: "solid", autoCodeSplitting: true }),  // ← CRITICAL: target must be "solid"
    tanstackStart({
      spa: {
        enabled: true,
        prerender: { outputPath: "/index" },
      },
    }),
    viteSolid({ ssr: true }),  // ← must come AFTER tanstackStart
  ],
});
```

### Critical rules
- `tanstackRouter({ target: "solid" })` — **`target: "solid"` is required**. The default is `"react"` and will break the build.
- `viteSolid()` must be listed **after** `tanstackStart()` in the plugins array.
- Vite v7+ is required for TanStack Start's `buildApp` post-build prerender hook.

## Router Configuration

```ts
// src/router.tsx
import { createRouter as createTanStackRouter } from "@tanstack/solid-router";
import { routeTree } from "./routeTree.gen";

export function getRouter() {
  const router = createTanStackRouter({
    routeTree,
    scrollRestoration: true,
    defaultPreload: "intent",
    defaultPreloadStaleTime: 0,
    defaultViewTransition: true,  // ← enables view transitions
  });
  return router;
}
```

### View transitions

`defaultViewTransition: true` in the router + CSS in `src/styles.css`:
```css
@view-transition {
  navigation: auto;
}
```

## SolidJS Patterns (not React)

| React | Solid |
|---|---|
| `useState` | `createSignal` |
| `useEffect` | `createEffect` |
| `useMemo` | `createMemo` |
| `React.FC<Props>` | `Component<Props>` from `solid-js` |
| `children: React.ReactNode` | `JSX.Element` or `ParentProps` |
| `className` | `class` |
| `dangerouslySetInnerHTML` | `innerHTML` directive |
| `.map(item => <El key={...}>)` | `<For each={...}>{item => <El>}</For>` |
| `{condition && <El>}` | `<Show when={condition}><El /></Show>` |
| `{condition ? <A> : <B>}` | `<Show when={condition} fallback={<B>}><A /></Show>` |
| `switch` / multiple conditions | `<Switch><Match when={...}>` |

**Key behavioral difference**: SolidJS components render **once**. Reactivity is driven by signals, not re-renders. Do not write code that assumes the component function runs on every state change.

## Animation

Use `solid-motionone` (`^1.0.4`) for animations.

```tsx
import { Motion } from "solid-motionone";

<Motion.div animate={{ opacity: 1 }} initial={{ opacity: 0 }}>
  content
</Motion.div>
```

> ⚠️ Do **not** use the `motion` package — it lacks a `./solid` subpath export and will fail at import time.

## Tauri Integration

This app is loaded by `apps/desktop` (Tauri). Key integration points:

| Setting | Value |
|---|---|
| Dev URL | `http://localhost:3001` |
| Frontend dist | `../../web/dist/client` (relative to `apps/desktop/src-tauri/`) |
| Before dev | `bun run --cwd ../web dev` |
| Before build | `bun run --cwd ../web build` |

### Production desktop auth risks ⚠️

Before shipping a production desktop build, these must be resolved:

1. **Tauri custom protocol origins** — Tauri serves from `tauri://localhost` (macOS/Linux) or `https://tauri.localhost` (Windows), not `http://localhost`. Auth servers must accept these origins.
2. **Better Auth `trustedOrigins`** — add `tauri://localhost` and `https://tauri.localhost` to the server's `trustedOrigins` list.
3. **CORS allowlist** — `apps/server` must allow requests from Tauri origins.
4. **Cookie `SameSite`/`Secure`** — `SameSite=Lax` cookies are blocked on cross-origin Tauri requests. Use `SameSite=None; Secure` or token-based auth.
5. **`app.security.csp`** — current CSP (`default-src 'self'; img-src 'self' data:`) blocks API calls. Add `connect-src` for the API server before shipping.

## Known Issues / Gotchas

1. **TanStack Intent skills are React-only** — `bun run intent:list` shows skills, but applying them produces React code. Adapt manually to Solid.
2. **`zod` is v3** (`^3.25.67`) — Zod v4 has breaking API changes. Do not upgrade without auditing all schema usage.
3. **`dist/server/` is build-time only** — do not deploy or reference it at runtime.
4. **No `@types/react` or `react-dom`** — SolidJS ships its own types. Do not install React type packages.
