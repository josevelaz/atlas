# Platform

## MVP

The MVP is a web app delivered as a Progressive Web App (PWA). It should feel as close to a native app as possible, including polished navigation, responsive layouts, offline-aware states where appropriate, and installable app behavior.

The interaction design should use purposeful motion, view transitions, and micro-interactions to make email triage feel fast, clear, and refined. Motion must respect `prefers-reduced-motion` and should prioritize performance on mobile devices.

## Future

Native iOS, Android, and desktop apps are deferred until the core workflow is validated.
