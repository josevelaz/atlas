# UI Library

The app will use [neobrutalism.dev](https://www.neobrutalism.dev/) as its UI component foundation.

The library is a neobrutalist React/Tailwind component collection based on shadcn/ui. It uses Tailwind CSS and `tw-animate-css`, which aligns with the intended PWA implementation and motion requirements.

The visual system should use the provided Tailwind theme tokens: OKLCH purple main/background colors, black borders, hard offset shadows, `radius-base: 5px`, `font-weight-base: 600`, and `font-weight-heading: 900`.
