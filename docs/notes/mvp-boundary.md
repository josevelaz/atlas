# MVP Boundary

The MVP includes:

- Gmail / Google Workspace and Outlook / Microsoft 365 connected accounts
- New-mail-only sync
- Send replies and compose new mail through connected accounts
- Sender Screener with Accept-to-category and Reject
- Fixed categories: Inbox, Feed, Paper Trail
- Handling states: Set Aside and Reply Later
- Unified cross-account views with account filters
- AI category suggestions
- AI thread summaries
- AI Inbox priority sort with visible badge/explanation
- AI action extraction synced to native provider tasks/calendars
- AI semantic search over synced threads with cited source threads
- AI propose-and-confirm commands for app-owned actions only; AI archive cleanup is out of scope
- PWA web app using neobrutalism.dev UI direction and tactile brutalist motion
- PWA notifications for important/high-priority Inbox threads and urgent Screener items

Anything beyond this is post-MVP unless explicitly pulled back into scope.
