# Search

## MVP

The MVP includes AI semantic search over synced threads only. Because the MVP organizes new mail only, semantic search can only return or answer from threads that arrived after the user connected their account.

Semantic search is exposed through a unified AI search/assistant entry point. The user can search, ask questions, and issue supported read-oriented commands such as "show emails from Stripe" or "find threads needing action."

Semantic search returns both a short answer when possible and cited source threads/results underneath. AI answers should not be shown without links back to the source threads they rely on.

## Future

Future search may include historical provider mailbox search across Gmail/Outlook history, but that is explicitly out of scope for the MVP because it would require broader mailbox access, indexing, and privacy considerations.
