# Action Integrations

## MVP

Confirmed action items sync by default to the native task and calendar tools for the connected account that owns the source thread:

- Gmail / Google Workspace: Google Tasks and Google Calendar
- Outlook / Microsoft 365: Microsoft To Do and Outlook Calendar

Extracted action items remain suggestions until the user confirms them.

## Future

Future integrations may include configurable destinations and third-party task and productivity tools such as Todoist, Apple Reminders, Notion, Linear, and similar apps. This should allow users to route work and personal action items to external systems such as Todoist if they choose.
