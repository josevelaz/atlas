# Onboarding

## MVP

The onboarding flow is:

1. Connect Gmail or Outlook/Microsoft 365 account.
2. Explain the product model: Screener, Inbox, Feed, Paper Trail, Set Aside, Reply Later, and AI assistant.
3. Explain that the MVP organizes new mail only and that everyone starts unscreened.
4. Start screening new mail as it arrives.

Onboarding should avoid heavy configuration before the user experiences value. Because the MVP starts with new mail only, empty states should include an interactive walkthrough explaining how the Screener, categories, and AI assistant will work. The MVP should not use a fake/demo mailbox.
