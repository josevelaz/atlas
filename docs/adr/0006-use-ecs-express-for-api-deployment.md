# Use ECS Express for API deployment

The API service deploys with AWS ECS Express Mode through Terraform's `aws_ecs_express_gateway_service` rather than raw ECS with an ALB, App Runner, or Lambda. ECS Express keeps the deployment close to ECS while abstracting the ALB, TLS endpoint, autoscaling, logs, and security groups that would otherwise add infrastructure complexity for the first production path. The trade-off is accepting an AWS-managed resource boundary, including possible managed-resource drift and no first-class custom API domain controls in the current Terraform resource. The API uses the generated `.on.aws` endpoint initially; if a custom API domain becomes required, the service should move to raw ECS and ALB Terraform so Route53, ACM, listeners, security groups, scaling, and logs are owned explicitly.
